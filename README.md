## The word

**alarmithmetic**: the sums you do at 3 a.m., counting the hours left before the alarm, and waking further with every answer.

## How it runs

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt`, checking it stays inside the 1–140 character gate before writing.
